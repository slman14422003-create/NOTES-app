# ملاحظاتي (Notes)

تطبيق ملاحظات للأندرويد بنفس لغة تصميم GITHUB-MANGER (خلفية سوداء، بطاقات رمادية مستديرة، لون أزرق، خط serif للعناوين)،
مع مزامنة تلقائية (تصدير + استيراد) مع Firebase Firestore.

## الميزات
- شاشة رئيسية: بحث، أربعة اختصارات سريعة (ملاحظة، قائمة، لصق من الحافظة، بحث)، فلاتر (الكل، المثبتة، القوائم، الأرشيف، المهملات)، قسم المثبتة ثم الأحدث بشبكة عمودين.
- وصول أسرع: شريط كتابة سريعة أسفل الشاشة، اختصارات عند الضغط المطوّل على أيقونة التطبيق (ملاحظة جديدة / قائمة جديدة)، واستقبال النص من أي تطبيق عبر «مشاركة».
- محرّر: حفظ تلقائي، ألوان، تثبيت، قوائم مهام قابلة للتحويل من/إلى نص، أرشفة، مهملات، حذف نهائي.
- تسجيل الدخول: «المتابعة بحساب Google» فقط، ولكل حساب ملاحظات منفصلة.
- مزامنة: تُرفع التعديلات تلقائيًا بعد ثوانٍ، وتُستورد تغييرات الأجهزة الأخرى عند فتح التطبيق وبزر المزامنة. الأحدث تعديلًا يفوز لكل ملاحظة.
- نسخة احتياطية: تصدير/استيراد ملف JSON من الإعدادات.
- يعمل بدون إنترنت (قاعدة SQLite محلية) وتُرفع التعديلات لاحقًا.

## التصميم والحركة
- ترويسة كبيرة تتقلّص أثناء التمرير، وشريط كتابة سريعة عائم يختفي عند النزول ويعود عند الصعود.
- بطاقات بزوايا 28dp، وتظهر البطاقات الجديدة فقط بحركة زنبركية (لا تُعاد عند المزامنة).
- محرّر بصفحة كاملة بلون الملاحظة مع انتقال لوني ناعم، وقائمة مهام تتحرك عند الإضافة والحذف.
- كل الأزرار تضغط وترتد بنابض (SpringAnimation)، وانتقالات الشاشات والحوارات بمنحنيات Material الحديثة، وشاشة الدخول بتوهج يتنفس.
- تحترم الحركة إعداد النظام «إزالة الحركات» (تُعطَّل كل الحركات تلقائيًا).

## الثيمات (المظهر)
- الإعدادات ← المظهر: الوضع **نظام / ليلي / نهاري**، ولون التطبيق **أبيض (الهوية الأصلية) / أزرق / أخضر / توتي / أصفر**.
- كل لون في التطبيق (الخلفيات، البطاقات، الأزرار، المفاتيح، الأيقونات، الحوارات، الشريط العلوي والسفلي، وألوان الملاحظات) يتبع الثيم المختار، ويتغير فورًا في كل الشاشات.
- 10 ثيمات (2 × 5) معرّفة في `res/values/theme_variants.xml` وتُضبط ألوانها كلها بخصائص `?attr/n_*`. لإضافة لون جديد انسخ أحد الثيمات وعدّل القيم، ثم أضفه في `ThemeKit`.
- شاشة البداية (Splash) تتبع نمط النظام فقط لأن النظام يرسمها قبل تحميل الثيم.

## اللغة واتجاه الواجهة
- من الإعدادات ← اللغة، أو من أزرار «العربية | English» في شاشة الدخول: لغة النظام / العربية / English.
- تغيير اللغة يقلب اتجاه الواجهة (RTL ↔ LTR) فورًا، وتُحفظ بعد إعادة التشغيل (Android 12 وأقدم عبر AppCompat، و13+ عبر إعدادات النظام «لغات التطبيقات»).
- محاذاة نص الملاحظات تتبع لغة النص نفسه: ملاحظة عربية داخل واجهة إنجليزية تُعرض من اليمين، والعكس.
- لغة نظام غير مدعومة تعود للإنجليزية.

## إعداد Firebase (مرة واحدة) — المشروع semo-7770a
1. **Authentication ← Get started** (إن لم تضغطه من قبل يظهر الخطأ `CONFIGURATION_NOT_FOUND`).
2. **Authentication ← Sign-in method**: فعّل **Google** فقط (اختر بريد الدعم واحفظ). تسجيل الدخول في التطبيق بحساب Google فقط.
3. **Firestore Database ← Create database** (وضع Production).
4. **Firestore ← Rules**: الصق محتوى `firebase/firestore.rules` ثم **Publish**
   (أو: `cd firebase && firebase deploy --only firestore:rules`).
5. إن كان مفتاح الـ API مقيّدًا بمواقع الويب فقط في Google Cloud Console فأزل القيد أو أضف قيد Android.

### تسجيل الدخول بحساب Google
1. **Project settings ← Your apps ← Add app ← Android**: اسم الحزمة `app.semo.notes`
   وبصمة **SHA-1** لمفتاح التوقيع: `BD:99:E8:37:77:70:CE:69:A1:C2:CD:C0:3F:B7:79:59:A9:46:AA:9F`
   (أضف أيضًا بصمة SHA-256 إن شئت، وبصمة مفتاح debug إن كنت ستجرب نسخة debug). لا تحتاج تنزيل `google-services.json`.
2. انسخ **Web client ID**: Authentication ← Sign-in method ← Google ← Web SDK configuration
   (شكله `123456-xxxx.apps.googleusercontent.com`).
3. مرّره للبناء بإحدى طريقتين:
   - سر في GitHub باسم `WEB_CLIENT_ID` (الأسهل؛ يقرؤه `build.yml` تلقائيًا).
   - أو الصقه في `Cfg.java` داخل `WEB_CLIENT_ID_FALLBACK`.
4. أعد بناء التطبيق وثبّته. إن ظهر خطأ رمزه 10 أو «تعذّر تسجيل Google» فالسبب غالبًا SHA-1 غير مسجّل أو Web client ID من مشروع آخر.

> لا يستخدم التطبيق مكتبات Firebase ولا `google-services.json`؛ يتصل عبر REST بنفس القيم (apiKey / projectId)،
> ويستعمل Credential Manager للحصول على توكن Google ثم يبادله بجلسة Firebase.

## قواعد الأمان (للمطوّر فقط، لا تظهر في التطبيق)
كل ملاحظة في `users/{uid}/notes/{noteId}`؛ القراءة والكتابة والحذف لصاحب الحساب فقط، مع التحقق من شكل الحقل وحجمه،
وكل ما عدا ذلك مغلق. حقل `syncedAt` يُضبط من الخادم ويُستخدم لسحب التغييرات فقط.

## البناء
نفس سير عمل GITHUB-MANGER: `.github/workflows/build.yml` (يتطلب أسرار التوقيع KEYSTORE_BASE64 / KEYSTORE_PASSWORD / KEY_ALIAS)،
أو شغّل `generate-keystore.yml` مرة واحدة في مستودع خاص. اسم الحزمة: `app.semo.notes`.

## التحديث من داخل التطبيق
- الإعدادات ← التحقق من التحديثات: يقرأ آخر Release في GitHub، يعرض الجديد وملاحظاته، ينزّل الـ APK داخل التطبيق بشريط تقدم ثم يشغّل المثبّت.
- يتحقق تلقائيًا بصمت عند فتح التطبيق كل 6 ساعات تقريبًا ويسألك قبل التنزيل (يمكن إيقافه، أو تجاهل إصدار معيّن).
- المستودع يُؤخذ تلقائيًا من GitHub Actions (`GITHUB_REPOSITORY`)، أو اكتبه من «مستودع التحديثات» بالشكل `owner/repo`.
- قبل التثبيت يتحقق من: الحجم، وبصمة SHA-256 المكتوبة في ملاحظات الإصدار، وأن الملف موقّع بنفس مفتاح النسخة المثبّتة. لذلك استخدم دائمًا نفس مفتاح التوقيع.
- يعمل مع المستودعات **العامة** فقط. وأول مرة سيطلب Android السماح للتطبيق بتثبيت التطبيقات.
- يعتمد على سير عمل `build.yml` الذي ينشر Release فيه الـ APK ورقم `versionCode` وبصمة الملف.

## الأمان والأداء
- جلسة الدخول: توكن التحديث مشفّر بمفتاح داخل Android Keystore، وتوكن الجلسة القصير في الذاكرة فقط. عند إلغاء الجلسة من Firebase يخرج التطبيق ويطلب الدخول مجددًا.
- المحرّر خاص: لا تستطيع تطبيقات أخرى فتح ملاحظاتك؛ المدخل العام الوحيد `CaptureActivity` (مشاركة نص / اختصارات) ويمرّر نصًا محدود الحجم فقط.
- قواعد Firestore (أعد نشرها): لكل مستخدم مساره الخاص فقط، بشرط Google وبريد موثّق؛ `createdAt` ثابت، `updatedAt` لا يرجع للخلف، ومعرّف الملاحظة بصيغة محددة.
- التحديث: تنزيل من أصول المستودع نفسه عبر https فقط، ورفض أي ملف غير أحدث أو بتوقيع مختلف أو لا يمكن التحقق منه.
- الإعدادات ← الخصوصية ← حماية الشاشة: يمنع لقطات الشاشة ويُخفي المحتوى في التطبيقات الأخيرة.
- الاستيراد من ملف: يتحقق من معرّفات الملاحظات وأحجامها وتواريخها.
- الأداء: قراءة القاعدة في خيط خلفي مع تأخير بسيط أثناء البحث، عرض 60 ملاحظة ثم «عرض المزيد»، فهارس SQLite وـ WAL، ولا مزامنة بلا إنترنت (تُرفع التعديلات تلقائيًا عند عودة الاتصال)، وسحب للأسفل للمزامنة.
- تشفير القاعدة المحلية: عنوان ونص كل ملاحظة مشفّر بـ AES-GCM بمفتاح محمي بـ Android Keystore (والبحث يتم داخل الذاكرة).
- كشف التعديل: في نسخ release يرفض التطبيق العمل إذا اختلف توقيعه عن توقيعك أو كان قابلًا للتنقيح.
- تشفير وقت البناء: معرّفات Firebase وWeb client ID ومستودع التحديث وبصمة الشهادة تُولَّد مبعثرة بمفتاح عشوائي جديد في كل بناء (`Secrets.java`) ثم يعمّي R8 كل الأسماء.
- الإعدادات ← الخصوصية ← حذف كل بياناتي: يمسح السحابة والجهاز.
- التفاصيل وخطوات Firebase/Google Cloud (تقييد مفتاح الـ API...): `firebase/SECURITY.md`.
